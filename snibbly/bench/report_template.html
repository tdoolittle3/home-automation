How this was run

Harness: snibbly/bench/compare_models.py in the home-automation repo, against llama-swap on :9292 (bypassing Langfuse). Temperature 0. Answer cap per item: 16,384 tokens for the thinking models (Inkling, Qwen3.6, big-30b-thinking, fast-8b) and 4,096 for the instruct models (vl-30b, coder-30b, vlm-8b); an answer that hits the cap fails. fast-8b's 16k quality run used a one-slot 32k-context variant (fast-8b-32k); its speed numbers are from the production fast-8b config. The production vision captioner was paused during the big-30b-thinking run. Math answers are exact-match on a final ANSWER: line; code is executed against unit tests; tool calls are checked by name and arguments; vision uses generated images of colored squares. Vision models other than vlm-8b load their vision projector beside the language model. vlm-8b sizes itself to leftover VRAM beside a resident model, so its decode speed reflects mostly-CPU inference. Inkling runs with --no-op-offload -ub 256 to fit the 8 GB card, which keeps its prompt processing on the CPU.
